# 專案工作台 Project Workbench

一個給一人 PM 用的輕量專案管理工具。純前端（HTML／CSS／JavaScript），不需要帳號、不需要伺服器，資料存在你自己的瀏覽器或 iCloud 資料夾。

**示範站**：https://hhhjustin.github.io/project-workbench/ （內建虛構資料，可以隨便點）

## 這是什麼

兩個獨立的工作區，共用同一套介面：

| | 私人版「日常的進度」 | 工作版「專案現場」 |
|---|---|---|
| 用途 | 每週安排自己的專案與生活事項、每日小記、週日回顧 | 管接案或公司專案：階段、文件、任務、待客戶確認、變更、決策、風險 |
| 誰看 | 自己 | 專案負責人／內部同事／客戶／供應商，四種視角 |
| 資料 | `data/personal.json` | `data/work.json` |

## 適合誰

- 一個人接案、或在小公司當 PM，案子不多但每個都要對客戶交代清楚。
- 不想為了三個案子養一套 Jira。
- 想要「開會時直接投影這個畫面」而不是另外做簡報。

## 三個使用情境

**1. 週一早上排自己的一週**（私人版）
設定每天可投入的時間，把專案任務拖進日期，生活事項（運動、家事）另一個顏色。週日回顧未完成的事，自己決定順延還是放掉。

**2. 跟著案子走階段**（工作版）
用範本開一個案子（切版案五階段、系統開發案六階段），之後階段可以自由改名、增刪、調換次序。每個階段有：
- **要交付的文件**：狀態「尚未開始／草稿／送審／已確認」，切到已確認自動記日期。
- **要做的事**：自己的 checklist，每條可設時間節點。
- **功能清單**：這個階段要做出來的功能，客戶與供應商都看得到。
- **推進條件**：自己勾選推進前要完成什麼；沒達成時推進鈕鎖住，但保留「略過條件推進」給例外。

期限燈號：紅＝今天到期或已過期、黃＝本週內、綠＝還有時間、空心＝沒設期限。

**3. 帶客戶開會**（工作版）
專案頁右上角「開會模式」：全螢幕、大字、只顯示客戶看得到的內容。本階段文件、待客戶確認、變更需求、里程碑、功能清單一頁看完。底部輸入框可以當場記下決策或新的待確認事項。Esc 離開。

## 怎麼開始

**只是看看**：打開示範站就好。

**自己用**：
1. 下載或 clone 這個 repo。
2. 用 Chrome 開 `工作版/index.html` 或 `私人版/index.html`（雙擊即可，不需要伺服器）。
3. 右上角按「連結 iCloud 資料夾」，選 `data/`。之後每次改動自動寫入 JSON；另一台電腦連同一個資料夾就共用資料。
4. 之後每次開啟按一下「重新連結」（瀏覽器規定每個工作階段要使用者點一下）。

沒連結資料夾時，資料存在瀏覽器的 localStorage，換瀏覽器或清快取就沒了。右上角也有「匯出／匯入」JSON 備援。

## 需要知道的限制

- **瀏覽器**：連結資料夾需要 Chrome 或 Edge（File System Access API）。Safari 只能用匯出／匯入。
- **權限只是模擬**：工作版的身分切換在前端做，用來設計與展示視角差異。前端隱藏不等於資料受保護；要真的給客戶登入看，必須有服務端。
- **單人使用**：兩台電腦不要同時編輯同一份 JSON，最後存的會蓋掉前一個。
- **沒有附件上傳**：文件只放連結（檔案或 Notion 頁面）。

## 資料結構（給想改的人）

- `工作版/app.js` 開頭的 `TEMPLATES` 是階段範本，`ROLE` 是權限矩陣（之後搬到服務端照抄即可）。
- 每個 `style.css` 開頭的 CSS 變數是改色入口。
- `shared/storage.js` 是兩版共用的儲存模組。
- 新版程式載入舊資料時會自動補欄位，不用手動遷移。

## 路線圖

- 把專案進度匯出成加密的靜態頁，給客戶用通關密語開啟。
- 私人／工作合成同一個 shell，側欄直接切換。
- 知識庫區塊。
